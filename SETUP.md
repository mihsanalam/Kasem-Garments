# Quick Setup Guide

## Prerequisites
- Node.js (v16+)
- npm or yarn
- Expo CLI: `npm install -g @expo/cli`

## Installation Steps

1. **Clone and Install**
   ```bash
   git clone https://github.com/Md-Mihsan-Alam/Kasem-Garments.git
   cd Kasem-Garments
   npm install
   ```

2. **Firebase Setup**
   - Create Firebase project at https://console.firebase.google.com/
   - Enable Authentication, Firestore Database, and Storage
   - Update `firebase.js` with your config

3. **Run the App**
   ```bash
   npm start
   ```
   Then scan QR code with Expo Go app or press 'a' for Android emulator
